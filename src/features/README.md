# `src/features/`

Une fonctionnalité par dossier (startup, catalog, prices, printing-browser, printing-detail, collection, wishlist, settings, backup, binder, notifications) : composants et hooks d'écran. `printing-browser` est la grille commune (spec § 2.1 : recherche, filtres, tri, pagination), que les onglets Catalogue, Collection et Souhaits configurent ; elle reçoit ses actions (✓, ♡) par ses props. Les routes de `src/app/` assemblent ces fonctionnalités.

`startup` est la racine de composition : `appSync.ts` crée la base (une seule connexion, partagée avec la tâche en arrière-plan), `fetch` et l'horloge. `notifications` annonce les nouvelles Extensions et les Alertes de prix. App ouverte : un message en haut de l'app pour les Extensions, une pastille sur l'onglet Souhaits pour les alertes ; sinon, une notification Android. Toucher une annonce d'Extension ouvre le Catalogue filtré, toucher une notification d'alertes ouvre les Souhaits. Une Alerte de prix n'est retenue (`wishlist_entry`) qu'une fois affichée ou envoyée. Le bandeau et les notifications ouvrent le Catalogue grâce au navigateur des onglets, que reçoit la prop `layout` de `Tabs`.
